## `whoami`

I am a Computer Science graduate and an **AI Engineer Intern at NiftyBooks FlexCo**.

I enjoy building systems that sit between research and product engineering: software with real users, measurable behavior, explicit trade-offs, and enough technical depth to survive beyond a demo.

My recent work spans:

- voice-driven GIS interfaces;
- exact and approximate graph algorithms compiled to WebAssembly;
- real-time collaborative architecture tooling;
- AI and computer-vision workflows backed by deterministic services and evaluation pipelines.

I am currently exploring **software engineering and applied-AI opportunities** involving backend systems, intelligent developer tools, model evaluation, infrastructure, or technically demanding product features.

```text
VOICE → INTENT PARSER → GIS ADAPTER → MAP ACTION
             │
             └── evaluated across 538 command cases


BALANCE GRAPH → EXACT SOLVER (small groups) → WASM → BROWSER
                     │
                     └── deterministic fallback at larger scale


CANVAS EVENT → SOCKET.IO → REDIS PUB/SUB → COLLABORATORS
                                  │
                                  └── synchronized graph state
```

### ⚖️ [CashFlow](https://github.com/SanishKumar/Cashflow)

A group-expense platform with its settlement engine written in C++ and compiled to WebAssembly.

**What makes it interesting**

- Exact minimum-payment search for up to 12 non-zero balances
- Deterministic fallback for larger groups
- Integer-cent arithmetic
- JWT authentication and token rotation
- RBAC, audit logs, exports, OCR
- Real-time group updates

## Currently exploring

### Voice-assisted indoor navigation

I am extending VoiceGIS toward indoor spatial interfaces for complex buildings such as hospitals, campuses, airports, and public facilities.

The direction combines:

```text
voice interaction
      +
indoor maps and routing
      +
accessible navigation
      +
XR / immersive guidance
```

The goal is not simply to place voice commands on a map, but to reduce the cognitive load of navigating unfamiliar indoor spaces.
